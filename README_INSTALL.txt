======================================================================
Центр Ортопедии и Травматологии Добрушкина
Медицинская информационная система (ОртоERP / Data Center)
РУКОВОДСТВО ПО УСТАНОВКЕ И ЭКСПЛУАТАЦИИ АВТОНОМНОГО СЕРВЕРА
======================================================================

Данный дистрибутив является полностью автономным и содержит все
необходимые компоненты: скомпилированный клиентский интерфейс (SPA),
REST API сервер (Express), базу данных SQLite (61 000+ пациентов),
готовые библиотеки зависимостей node_modules и инструменты администрирования.

----------------------------------------------------------------------
1. СИСТЕМНЫЕ ТРЕБОВАНИЯ
----------------------------------------------------------------------
• Операционная система: Windows 10 / 11 / Windows Server 2016-2025 (x64)
• Режим Zero-Dependency: Дистрибутив содержит встроенный портативный Node.js (tools\node\node.exe)
  и не требует предварительной установки Node.js на чистом компьютере!
• Для абсолютно чистых систем Windows (без Visual C++): в папке \installers находится vc_redist.x64.exe
  (или запустите "install_prerequisites.bat" от имени Администратора).
• Оперативная память: от 4 ГБ
• Свободное место на диске: от 1.5 ГБ (с учетом автоматических бэкапов)

----------------------------------------------------------------------
2. СТРУКТУРА КАТАЛОГА ДИСТРИБУТИВА
----------------------------------------------------------------------

----------------------------------------------------------------------
3. БЫСТРЫЙ СТАРТ (STANDALONE РЕЖИМ)
----------------------------------------------------------------------
Для запуска клиники на одном компьютере или в локальной сети без IIS:
1. Запустите файл "start.bat" двойным щелчком мыши.
2. Сервер автоматически запустится на порту 5000, выполнит моментальный
   снимок базы данных в папку backups\ и откроет браузер по адресу:
   http://localhost:5000
3. Для доступа с других компьютеров клиники по локальной сети:
   Откройте в браузере IP-адрес сервера, например: http://192.168.1.50:5000
4. Для остановки сервера запустите "stop.bat".

----------------------------------------------------------------------
4. РАЗВЕРТЫВАНИЕ В MICROSOFT IIS (РЕКОМЕНДУЕТСЯ ДЛЯ СЕРВЕРА КЛИНИКИ)
----------------------------------------------------------------------
Для работы по стандартному порту 80 (http://клиника / http://192.168.1.50):
1. Щелкните правой кнопкой мыши по файлу "setup_iis.bat" и выберите
   "Запуск от имени администратора".
2. Скрипт проверит наличие компонентов IIS, модулей URL Rewrite 2.1 и
   Application Request Routing (ARR), создаст сайт "OrthopedClinic"
   и откроет порт 80 в Windows Firewall.
3. Зарегистрируйте автозапуск бэкенда через "install_service.bat" от имени
   Администратора, чтобы служба стартовала при включении сервера.

----------------------------------------------------------------------
5. РЕЗЕРВНОЕ КОПИРОВАНИЕ (BACKUP)
----------------------------------------------------------------------
• Система использует технологию атомарного моментального копирования
  SQLite "VACUUM INTO" на изолированном подключении.
• Копирование выполняется без остановки сервера и блокировки пользователей.
• Автоматический снимок создается при каждом старте бэкенда в папку \backups.
• В файле appsettings.json можно настроить глубину хранения (по умолчанию 7 копий).

# Клинический реестр специальных ортопедических тестов для 180 шаблонов МИС
## Стандарт трехуровневой стратификации физикального обследования (Версия 4.2 — МИС-Интегратор)

---

### Аннотация и архитектура интеграции в МИС

Настоящий реестр представляет собой унифицированный справочник ортопедического физикального обследования для **180 стандартизированных клинических шаблонов**, сгруппированных по 8 анатомо-функциональным кластерам. 

Для каждого шаблона специальные ортопедические тесты распределены по трем строго детерминированным клиническим уровням (Tiers), определяющим логику валидации полей и обязательность заполнения в экранных формах МИС:

```
  +-------------------------------------------------------------------------------------------------+
  |                  ЛОГИКА ОБРАБОТКИ ОРТОПЕДИЧЕСКИХ ТЕСТОВ В ИНТЕРФЕЙСЕ МИС                        |
  +--------------------+---------------------------------------+------------------------------------+
  | Уровень приоритета | Клиническое назначение                | Системное поведение в МИС          |
  +--------------------+---------------------------------------+------------------------------------+
  | TIER 1 (ВЫСОКИЙ)   | Высокочувствительные (SnNout) тесты   | Обязательные поля («Hard Stop»).   |
  |                    | скрининга 1-й линии, патогномоничные  | Протокол приема не сохраняется     |
  |                    | симптомы и тесты выявления красных    | без фиксации результата            |
  |                    | флагов (неотложных состояний).        | (Положительный / Отрицательный).   |
  +--------------------+---------------------------------------+------------------------------------+
  | TIER 2 (СРЕДНИЙ)   | Высокоспецифичные (SpPin) подтверж-   | Рекомендуемые поля («Soft Alert»). |
  |                    | дающие пробы, тесты дифференциальной  | Автоматически активируются при     |
  |                    | диагностики и сопутствующей мульти-   | положительном Tier 1 или нети-     |
  |                    | структурной нестабильности.           | пичной картине заболевания.        |
  +--------------------+---------------------------------------+------------------------------------+
  | TIER 3 (НИЗКИЙ)    | Экспертные динамические пробы,        | Дополнительные поля по требованию. |
  |                    | редкие эпонимические тесты, оценка    | Предназначены для профильных экс-  |
  |                    | генерализованной гипермобильности и   | пертных консилиумов, научных баз и |
  |                    | интраоперационного картирования.      | предоперационного планирования ВМП.|
```

## Раздел 3. Руководство по валидации и маппингу структуры данных в МИС

Для технического отдела интеграции МИС рекомендуются следующие правила валидации экранных форм:

1. **Модуль жесткой валидации («Hard Stop» для Tier 1):**
   * Каждый тест из колонки **Tier 1** должен быть представлен в интерфейсе МИС отдельным логическим элементом (радиобаттон `[+] Положительно` / `[-] Отрицательно` / `[N/A] Не применимо` с обязательным указанием причины, например: «Иммобилизация гипсовой лонгетой», «Острый болевой синдром»).
   * Блокировка кнопки «Подписать и закрыть протокол», если не заполнен хотя бы один параметр Tier 1 для выбранного основного диагноза.
2. **Модуль условной активации («Conditional Logic» для Tier 2):**
   * Если в блоке Tier 1 хотя бы один тест отмечен как `[+] Положительно`, система автоматически разворачивает блок тестов **Tier 2** как рекомендованный диагностический маршрут.
3. **Модуль структурированного кодирования в HL7 FHIR / OpenEHR:**
   * Каждому тесту присваивается уникальный идентификатор: `TEST_ID = {CLUSTER}_{TEMPLATE_NUM}_{TIER}_{TEST_SLUG}` (например: `KNEE_004_T1_LACHMAN`).
   * Результат теста кодируется стандартными концептами SNOMED CT:
     - Положительный результат: `10828004 | Positive (qualifier value)`
     - Отрицательный результат: `260385009 | Negative (qualifier value)`
     - Сомнительный / слабоположительный: `42425007 | Equivocal (qualifier value)`
4. **Контроль безопасности инвазивных процедур:**
   * Перед формированием информированного согласия на блокаду, пункцию или PRP-терапию система МИС производит кросс-проверку обязательных тестов Tier 1 (например, отсутствие признаков острого септического воспаления или тромбоза).
